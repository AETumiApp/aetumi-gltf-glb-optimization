# glTF / GLB Optimization Demo

A small, **self-contained, interactive Three.js (r160) + WebGL** demo. No build step, no framework — open `index.html` in a browser and it runs. Real WebGL rendering, not an MP4 or GIF — open DevTools and inspect it.

**Live:** https://aetumi.app/news/optimize-gltf-glb-threejs/
**Article:** https://aetumi.app/news/optimize-gltf-glb-threejs/

## Run locally
```bash
npx serve .   # or just open index.html
```

## Tech
Vanilla **Three.js r160** via ES-module import map (jsDelivr), no bundler, no React/R3F.

**Topics:** glTF, GLB, mesh optimization, triangle density, draco, web 3D asset pipeline
